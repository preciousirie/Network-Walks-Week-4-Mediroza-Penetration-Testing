## Mediroza General Hospital – Black-Box Vulnerability Assessment

**Internship:** Network Walks Cybersecurity Internship  
**Batch:** B084  
**Week:** 4  
**Assessment Type:** Authorized Educational Security Assessment

### Project Background

This assessment involved investigating the security posture of the Mediroza General Hospital educational web application.

The exercise focused on identifying potential security weaknesses, examining authentication mechanisms, assessing document protection and documenting relevant findings.

### Assessment Objectives

- Conduct initial reconnaissance.
- Identify potential web application vulnerabilities.
- Investigate authentication security.
- Assess password-protected PDF documents.
- Examine potential information exposure.
- Document findings, evidence and remediation recommendations.

### Scope

The assessment was limited to the educational application and the authorized testing activities provided by the tutor.

All patient records and documents used were simulated.

### Assessment Approach

The project followed a structured assessment process involving reconnaissance, vulnerability identification, document security assessment, evidence collection and reporting.

### Expected Deliverables

- Technical assessment documentation.
- Supporting screenshots and evidence.
- Identified security findings.
- Risk and impact observations.
- Recommended remediation measures.
